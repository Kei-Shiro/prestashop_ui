Apprendre Vue.js de zéro à expert

Ce cahier couvre tout ce dont vous avez besoin pour devenir un développeur Vue.js compétent — des bases de la réactivité à la gestion d'état avancée avec Pinia.

Qu'est-ce que Vue.js ?

Vue.js est un framework JavaScript progressif pour construire des interfaces utilisateur. Il est conçu pour être adopté progressivement — vous pouvez l'utiliser pour une seule page ou pour toute une application complexe.

⚡

Réactif

Le DOM se met à jour automatiquement quand les données changent.

●

Composants

Construisez des UIs en combinant de petits composants réutilisables.

→

Progressif

Intégrez Vue dans un projet existant ou construisez une SPA complète.

◆

Composition API

Organisez votre logique par fonctionnalité, pas par option.

Anatomie d'un fichier .vue (SFC)

Un Single File Component (SFC) regroupe le template HTML, le script JS et le style CSS dans un seul fichier.

VUEMonComposant.vue
<!-- 1. TEMPLATE : ce qui s'affiche -->
<template>
  <div class="hello">
    <h1>{{ message }}</h1>
    <button @click="changerMessage">Changer</button>
  </div>
</template>

<!-- 2. SCRIPT : la logique -->
<script setup>
import { ref } from 'vue'

const message = ref('Bonjour Vue !')

function changerMessage() {
  message.value = 'Message changé !'
}
</script>

<!-- 3. STYLE : la mise en forme -->
<style scoped>
.hello {
  text-align: center;
  color: #42b883;
}
</style>
◆ Bonne pratique

<script setup> est la syntaxe recommandée pour la Composition API — tout ce que vous déclarez est automatiquement accessible dans le template, sans besoin de return.

Template & Directives

Vue utilise une syntaxe de template HTML enrichie de directives (préfixées par v-) pour lier dynamiquement les données au DOM.

Interpolation — Afficher des données

VUE TEMPLATEAffichage dynamique
<template>
  <!-- Texte simple -->
  <p>{{ nom }}</p>                      <!-- "Alice" -->
  <p>{{ age + 1 }}</p>                 <!-- "26" -->
  <p>{{ ok ? 'Oui' : 'Non' }}</p>     <!-- Expression JS -->

  <!-- HTML brut (attention aux XSS !) -->
  <div v-html="htmlContent"></div>
</template>

<script setup>
const nom = 'Alice'
const age = 25
const ok = true
const htmlContent = '<strong>Texte en gras</strong>'
</script>

v-bind — Lier des attributs HTML

VUE TEMPLATEv-bind (:)
<template>
  <!-- Syntaxe complète -->
  <img v-bind:src="imageUrl" v-bind:alt="imageAlt" />

  <!-- Syntaxe raccourcie (recommandée) -->
  <img :src="imageUrl" :alt="imageAlt" />

  <!-- Lier des classes dynamiquement -->
  <div :class="{ actif: estActif, erreur: aErreur }">...</div>
  <div :class="[classeBase, estActif ? 'actif' : '']">...</div>

  <!-- Lier des styles dynamiquement -->
  <div :style="{ color: couleur, fontSize: taille + 'px' }">...</div>

  <!-- Bouton désactivé conditionnellement -->
  <button :disabled="chargement">Envoyer</button>
</template>

v-if / v-else-if / v-else — Rendu conditionnel

VUE TEMPLATEConditions
<template>
  <!-- v-if crée/détruit l'élément dans le DOM -->
  <div v-if="score >= 90">🏆 Excellent !</div>
  <div v-else-if="score >= 60">✅ Bien</div>
  <div v-else>❌ À améliorer</div>

  <!-- v-show : garde dans le DOM, change display -->
  <!-- Préférer v-show pour des bascules fréquentes -->
  <div v-show="menuOuvert">Menu contextuel</div>

  <!-- <template> pour grouper sans ajouter de div -->
  <template v-if="connecte">
    <p>Bienvenue !</p>
    <button>Se déconnecter</button>
  </template>
</template>

v-for — Rendu de listes

VUE TEMPLATEBoucles
<template>
  <!-- Tableau simple — TOUJOURS ajouter :key -->
  <ul>
    <li v-for="fruit in fruits" :key="fruit">{{ fruit }}</li>
  </ul>

  <!-- Avec l'index -->
  <li v-for="(fruit, index) in fruits" :key="index">
    {{ index + 1 }}. {{ fruit }}
  </li>

  <!-- Tableau d'objets -->
  <div v-for="user in users" :key="user.id">
    <h3>{{ user.nom }}</h3>
    <p>{{ user.email }}</p>
  </div>

  <!-- Plage de nombres -->
  <span v-for="n in 5" :key="n">★</span>  <!-- ★★★★★ -->
</template>

<script setup>
const fruits = ['Mangue', 'Litchi', 'Ananas']
const users = [
  { id: 1, nom: 'Alice', email: 'alice@mail.com' },
  { id: 2, nom: 'Bob', email: 'bob@mail.com' }
]
</script>

v-on — Écouter les événements

VUE TEMPLATEv-on (@)
<template>
  <!-- Syntaxe raccourcie @ -->
  <button @click="incrementer">+1</button>
  <button @click="compteur++">Inline</button>

  <!-- Passer l'événement natif -->
  <input @input="onInput($event)" />

  <div @click.stop="action">Div</div>              <!-- stopPropagation -->
  <button @click.once="uneSeuleFois">Click</button>  <!-- déclenche une fois -->
</template>

Réactivité

Le système de réactivité de Vue 3 est le cœur du framework. Quand les données réactives changent, le DOM se met à jour automatiquement.

ref() — Pour les valeurs primitives

JAVASCRIPTref()
<script setup>
import { ref } from 'vue'

// ref() pour : string, number, boolean, null, undefined
const nom = ref('Alice')
const age = ref(25)
const connecte = ref(false)
const liste = ref([]) // fonctionne aussi avec tableaux/objets

// Dans le script : accès via .value
nom.value = 'Bob'
age.value++
connecte.value = true
liste.value.push({ id: 1, titre: 'Tâche 1' })

// Dans le template : pas besoin de .value !
// {{ nom }}  ✓    {{ nom.value }}  ✗
</script>

reactive() — Pour les objets et tableaux

JAVASCRIPTreactive()
<script setup>
import { reactive } from 'vue'

// reactive() pour les objets
const utilisateur = reactive({
  nom: 'Alice',
  age: 25,
  adresse: {
    ville: 'Antananarivo',
    pays: 'Madagascar'
  }
})

// Modification : sans .value !
utilisateur.nom = 'Bob'
utilisateur.adresse.ville = 'Toamasina'

// ⚠️ Attention : ne jamais réassigner l'objet entier !
// utilisateur = { nom: 'Carol' }  // ❌ perd la réactivité
utilisateur.nom = 'Carol'         // ✅ modifier les propriétés
</script>

<template>
  <p>{{ utilisateur.nom }} habite à {{ utilisateur.adresse.ville }}</p>
</template>

ref() — Quand l'utiliser

// Primitives
const compteur = ref(0)
const titre = ref('')
const visible = ref(true)

// Accès dans le script
compteur.value++

reactive() — Quand l'utiliser

// Objets complexes
const form = reactive({
  nom: '',
  email: '',
  age: 0
})

// Accès direct
form.nom = 'Alice'

Exemple complet : Compteur réactif

VUECompteur.vue
<template>
  <div class="compteur">
    <h2>Compteur : {{ valeur }}</h2>
    <button @click="decrementer" :disabled="valeur === 0">-</button>
    <button @click="incrementer">+</button>
    <button @click="reinitialiser">Reset</button>
    <p v-if="valeur > 10" style="color:orange">Valeur élevée !</p>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const valeur = ref(0)

function incrementer() { valeur.value++ }
function decrementer() { if (valeur.value > 0) valeur.value-- }
function reinitialiser() { valeur.value = 0 }
</script>

Computed & Watchers

Les propriétés calculées (computed) et les observateurs (watch) permettent de réagir aux changements de données.

computed() — Valeurs dérivées

JAVASCRIPTcomputed()
<script setup>
import { ref, computed } from 'vue'

const prenom = ref('Alice')
const nom = ref('Dupont')
const prix = ref(100)
const tva = ref(0.2)
const panier = ref([
  { nom: 'Livre', prix: 20 },
  { nom: 'Stylo', prix: 5 },
  { nom: 'Cahier', prix: 8 }
])

// computed : se recalcule SEULEMENT si dépendances changent
const nomComplet = computed(() => `${prenom.value} ${nom.value}`)
const prixTTC = computed(() => (prix.value * (1 + tva.value)).toFixed(2))
const totalPanier = computed(() =>
  panier.value.reduce((acc, item) => acc + item.prix, 0)
)
const nbArticles = computed(() => panier.value.length)
</script>

<template>
  <p>{{ nomComplet }} <!-- "Alice Dupont" --></p>
  <p>Prix TTC : {{ prixTTC }} € <!-- "120.00 €" --></p>
  <p>{{ nbArticles }} articles — Total : {{ totalPanier }} €</p>
</template>
◆ Computed vs Méthode

Un computed est mis en cache et ne se recalcule que si ses dépendances changent. Une méthode recalcule à chaque rendu. Utilisez computed pour des valeurs dérivées, les méthodes pour des actions avec effets de bord.

watch() — Observer les changements

JAVASCRIPTwatch()
<script setup>
import { ref, watch, watchEffect } from 'vue'

const recherche = ref('')
const userId = ref(1)
const parametres = ref({ page: 1, tri: 'asc' })

// watch : observe une source précise
watch(recherche, (nouvelleVal, ancienneVal) => {
  console.log(`Recherche : "${ancienneVal}" → "${nouvelleVal}"`)
  rechercherAPI(nouvelleVal)
})

// watch avec options
watch(userId, async (id) => {
  userData.value = await fetchUser(id)
}, {
  immediate: true,  // déclencher immédiatement au montage
})

// Observer un objet profond
watch(parametres, (val) => {
  chargerDonnees(val)
}, { deep: true })  // surveille les propriétés imbriquées

// watchEffect : observe toutes les dépendances automatiquement
watchEffect(() => {
  console.log(`User ${userId.value} recherche "${recherche.value}"`)
  // Déclenché automatiquement si userId OU recherche change
})
</script>

Lifecycle Hooks

Les hooks de cycle de vie permettent d'exécuter du code à des moments précis de la vie d'un composant.

onBeforeMount

Avant l'insertion dans le DOM. Composant compilé mais pas encore affiché.

onMounted

Composant inséré dans le DOM. Idéal pour les requêtes API et manipulations DOM.

onBeforeUpdate

Avant une mise à jour réactive du DOM.

onUpdated

Après chaque mise à jour du DOM. Éviter les modifications d'état ici.

onBeforeUnmount

Avant que le composant soit retiré. Nettoyer les timers, listeners.

onUnmounted

Composant retiré. Tout nettoyage final ici.

Exemple concret : Minuteur avec nettoyage

VUEMinuteur.vue
<script setup>
import { ref, onMounted, onUnmounted, onBeforeUnmount } from 'vue'

const secondes = ref(0)
const utilisateur = ref(null)
let timer = null

// Démarre le timer et charge les données au montage
onMounted(async () => {
  console.log('Composant monté !')

  // Démarrer un timer
  timer = setInterval(() => {
    secondes.value++
  }, 1000)

  // Charger des données
  utilisateur.value = await fetch('/api/user').then(r => r.json())

  // Accès DOM direct avec ref template
  // monInput.value.focus()
})

// Nettoyage CRUCIAL avant le démontage
onBeforeUnmount(() => {
  console.log('Nettoyage...')
  clearInterval(timer)  // Évite les fuites mémoire !
})
</script>

<template>
  <div>
    <p>Temps écoulé : {{ secondes }}s</p>
    <p v-if="utilisateur">Bienvenue {{ utilisateur.nom }}</p>
  </div>
</template>
⚠ Important

Toujours nettoyer les timers (setInterval/setTimeout), les event listeners (addEventListener) et les subscriptions dans onBeforeUnmount pour éviter les fuites mémoire.

Composition API

La Composition API permet d'organiser la logique par fonctionnalité (pas par option) et de la réutiliser via des "composables".

Composables — Logique réutilisable

Un composable est une fonction qui encapsule de la logique réactive et peut être partagée entre plusieurs composants.

JAVASCRIPTcomposables/useCompteur.js
import { ref, computed } from 'vue'

// Convention : nom commence par "use"
export function useCompteur(valeurInitiale = 0) {
  const compteur = ref(valeurInitiale)
  const estPositif = computed(() => compteur.value > 0)

  function incrementer(n = 1) { compteur.value += n }
  function decrementer(n = 1) { compteur.value -= n }
  function reinitialiser() { compteur.value = valeurInitiale }

  return { compteur, estPositif, incrementer, decrementer, reinitialiser }
}
JAVASCRIPTcomposables/useFetch.js — Exemple avancé
import { ref, watch, toValue } from 'vue'

export function useFetch(url) {
  const data = ref(null)
  const chargement = ref(false)
  const erreur = ref(null)

  async function charger() {
    chargement.value = true
    erreur.value = null
    try {
      const res = await fetch(toValue(url))
      if (!res.ok) throw new Error(`HTTP ${res.status}`)
      data.value = await res.json()
    } catch (e) {
      erreur.value = e.message
    } finally {
      chargement.value = false
    }
  }

  // Se recharge si l'URL change
  watch(() => toValue(url), charger, { immediate: true })

  return { data, chargement, erreur, charger }
}

// ---- Utilisation dans un composant ----
// import { useFetch } from '@/composables/useFetch'
// const { data: users, chargement } = useFetch('/api/users')

Formulaires & v-model

v-model crée une liaison bidirectionnelle entre un champ de formulaire et une variable réactive.

Vue Router

Vue Router est le routeur officiel de Vue.js pour créer des applications SPA (Single Page Application) avec navigation entre pages.

Configuration du routeur

JAVASCRIPTsrc/router/index.js
import { createRouter, createWebHistory } from 'vue-router'
import Accueil from '@/views/Accueil.vue'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    // Route simple
    { path: '/', name: 'accueil', component: Accueil },

    // Lazy loading (chargement à la demande)
    {
      path: '/articles',
      name: 'articles',
      component: () => import('@/views/Articles.vue')
    },

    // Route avec paramètre dynamique
    {
      path: '/articles/:id',
      name: 'article-detail',
      component: () => import('@/views/ArticleDetail.vue'),
      props: true  // passe :id comme prop
    },

    // Routes imbriquées
    {
      path: '/admin',
      component: () => import('@/layouts/AdminLayout.vue'),
      meta: { requiresAuth: true },
      children: [
        { path: '', component: () => import('@/views/admin/Dashboard.vue') },
        { path: 'users', component: () => import('@/views/admin/Users.vue') }
      ]
    },

    // Redirect & 404
    { path: '/ancienne-url', redirect: '/articles' },
    { path: '/:pathMatch(.*)*', component: () => import('@/views/NotFound.vue') }
  ]
})

// Navigation Guard global
router.beforeEach((to, from) => {
  if (to.meta.requiresAuth && !estConnecte()) {
    return { name: 'login' }
  }
})

export default router

Pinia — Gestion d'état

Pinia est le gestionnaire d'état officiel de Vue 3. Plus simple que Vuex, il suit le pattern store pour partager l'état entre composants.

Créer un store

JAVASCRIPTstores/useUtilisateurStore.js
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

// Convention : "use" + nom + "Store"
export const useUtilisateurStore = defineStore('utilisateur', () => {
  // STATE — les données réactives
  const utilisateur = ref(null)
  const token = ref(localStorage.getItem('token'))
  const chargement = ref(false)

  // GETTERS — computed properties
  const estConnecte = computed(() => !!token.value)
  const nomComplet = computed(() =>
    utilisateur.value ? `${utilisateur.value.prenom} ${utilisateur.value.nom}` : ''
  )
  const estAdmin = computed(() => utilisateur.value?.role === 'admin')

  // ACTIONS — les fonctions
  async function seConnecter({ email, mdp }) {
    chargement.value = true
    try {
      const res = await fetch('/api/login', {
        method: 'POST',
        body: JSON.stringify({ email, mdp })
      })
      const { user, accessToken } = await res.json()
      utilisateur.value = user
      token.value = accessToken
      localStorage.setItem('token', accessToken)
    } finally {
      chargement.value = false
    }
  }

  function seDeconnecter() {
    utilisateur.value = null
    token.value = null
    localStorage.removeItem('token')
  }

  return {
    utilisateur, token, chargement,  // state
    estConnecte, nomComplet, estAdmin,  // getters
    seConnecter, seDeconnecter            // actions
  }
})

Axios — Configuration recommandée

JAVASCRIPTlib/axios.js — Instance configurée
import axios from 'axios'

const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL || 'https://api.exemple.com',
  timeout: 10000,
  headers: { 'Content-Type': 'application/json' }
})

// Intercepteur : ajouter le token automatiquement
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// Intercepteur : gérer les erreurs globalement
api.interceptors.response.use(
  (response) => response,
  (erreur) => {
    if (erreur.response?.status === 401) {
      localStorage.removeItem('token')
      window.location.href = '/login'
    }
    return Promise.reject(erreur)
  }
)

Checklist de l'excellence Vue

  • ✓

    Toujours utiliser :key dans v-for

    Une clé unique stable (id, pas l'index) permet à Vue d'optimiser le DOM virtuel.

  • ✓

    Ne jamais utiliser v-if et v-for ensemble

    Utilisez un <template v-if> à l'extérieur ou filtrez les données en amont via computed.

  • ✓

    Nettoyer dans onBeforeUnmount

    Timers, event listeners, subscriptions — toujours nettoyer pour éviter les fuites mémoire.

  • ✓

    Variables d'environnement avec VITE_

    Préfixez toutes vos vars .env avec VITE_ pour les exposer au client : VITE_API_URL.

  • ✓

    Préférer la Composition API

    Plus flexible, meilleure inférence TypeScript, logique réutilisable via composables.

  • ✓

    Lazy-loader les routes et composants lourds

    Utilisez des imports dynamiques () => import(...) pour réduire le bundle initial.

  • ✓

    Une responsabilité par composant

    Un composant = une chose. Découpez si ça fait plus de 200 lignes ou gère plusieurs préoccupations.

  • ✓

    Nommage cohérent

    Composants : PascalCase. Composables : useCamelCase. Stores : useCamelCaseStore.

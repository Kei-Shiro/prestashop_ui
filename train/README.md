# Formation Interne : PrestaShop UI (Vue 3)

Bienvenue dans le parcours d'apprentissage du projet **PrestaShop UI**. 
Ce dossier a été conçu comme une formation interne senior pour vous permettre de maîtriser l'architecture de l'application, l'intégration de l'API PrestaShop, et les bonnes pratiques Vue 3 utilisées ici.

## Objectifs de la formation
- Comprendre la stack technique (Vue 3, Pinia, Axios, fast-xml-parser).
- Maîtriser la manipulation de l'API PrestaShop (qui utilise du XML).
- Comprendre l'architecture Feature-Based (Front-office & Back-office).
- Être capable de debugger, refactoriser et créer de nouvelles fonctionnalités de A à Z.

## Structure du parcours

1. **`ui/`** : Maîtrise des composants Vue, layouts (Admin/Shop), et formulaires.
2. **`vue-architecture/`** : Composition API, Composables, Pinia, Vue Router.
3. **`api-integration/`** : Communication Axios, Sérialisation/Désérialisation XML PrestaShop.
4. **`typescript/`** : Types, interfaces métiers (Order, Product, etc.), et generics.
5. **`exercises/`** : Exercices progressifs par niveau pour valider vos acquis.
6. **`mini-projects/`** : Fonctionnalités complètes à recréer (ex: Mini-gestionnaire de stock).
7. **`challenges/`** : Défis avancés d'architecture et de performance.
8. **`debugging/`** : Résolution de bugs réels (souvent liés au parsing XML ou à la réactivité).
9. **`cheatsheets/`** : Fiches mémo rapides pour la syntaxe et les utilitaires du projet.
10. **`advanced/`** : Optimisations, design patterns et architecture avancée.

## Comment utiliser ce dossier ?
Chaque fichier contient :
- **La théorie** dans le contexte spécifique du projet.
- **Des exemples concrets** tirés du code de production.
- **Des exercices pratiques** pour s'entraîner.
- **Les solutions commentées**.
- **Des astuces "Senior"** et les pièges à éviter.

Commencez par lire les `cheatsheets`, puis suivez les modules dans l'ordre (UI -> Vue Architecture -> API) avant de vous lancer dans les `exercises` et `mini-projects`.
